# Спецификация языка MiniSharp

## Введение

MiniSharp — учебный императивный язык для изучения принципов лексического, синтаксического анализа и интерпретации программ. На текущей итерации поддерживаются целочисленные выражения, функция `main`, вывод, ввод целого числа и встроенные арифметические функции. Синтаксические конструкции, которые пока не выполняются интерпретатором (например, объявления переменных, условные операторы, циклы, строки и логические значения), не входят в текущую грамматику исполняемой части языка.

### Текущие возможности
- **Тип данных:** `int` — 64-битное знаковое целое. Неявные преобразования не поддерживаются.
- **Вычисления:** арифметические операции `+`, `-`, `*`, `/`, унарный минус и скобки.
- **Встроенные функции:** `abs`, `sqr`, `min`, `max`.
- **Ввод и вывод:** `readInt()` и `print`.
- **Точка входа:** `func main()`, инструкции выполняются последовательно.

### Планируемые возможности
Объявления переменных, строковые и логические типы, условные операторы, циклы и функции с параметрами/возвращаемыми значениями могут рассматриваться в следующих итерациях и не заявляются как реализованные сейчас.

## Лексика

Лексический анализатор разбивает исходный код на поток токенов. Пробельные символы (пробелы, табуляции, переносы строк) игнорируются, кроме случаев разделения идентификаторов и ключевых слов.

### Алфавит
- **Буквы:** Латинские буквы верхнего и нижнего регистра (`a-z`, `A-Z`).
- **Цифры:** Арабские цифры (`0-9`).
- **Специальные символы:** `_` (подчёркивание).
- **Разделители и операторы:** `{ } ( ) ; , + - * / = < > ! & | "`.

### Ключевые слова
Зарезервированные идентификаторы, которые не могут использоваться как имена переменных или функций:

| Ключевое слово | Назначение |
| :--- | :--- |
| `let` | Объявление переменной |
| `if` | Условный оператор |
| `else` | Альтернативная ветвь условия |
| `while` | Цикл с предусловием |
| `func` | Объявление функции |
| `return` | Возврат значения из функции |
| `print` | Вывод значения в стандартный поток вывода |
| `readInt` | Чтение значения из стандартного потока ввода |
| `true` | Логическая истина |
| `false` | Логическая ложь |
| `main` | Точка входа в программу |

Ключевые слова `let`, `if`, `else`, `while`, `return`, `true` и `false` распознаются лексером, но их конструкции не входят в текущую грамматику исполняемой части языка.

### Идентификаторы
Имена переменных, функций и параметров должны начинаться с буквы или символа `_`, за которыми могут следовать буквы, цифры или `_`.
- **Корректно:** `counter`, `_tempValue`, `user1`, `MAX_SIZE`.
- **Некорректно:** `1var`, `my-var`, `class`.
- **Важно:** Язык MiniSharp является **регистрозависимым**. Ключевые слова должны писаться точно так, как указано в таблице (например, `let`, `if`, `readInt`). Написание `Let`, `IF` или `readint` будет распознано как обычный идентификатор, а не как ключевое слово.

### Литералы
1. **Целочисленные литералы (`int`):** Последовательность цифр. Отрицательные числа формируются с помощью отдельного токена арифметического оператора минуса (`-`), за которым следует положительный целочисленный литерал.
    - Примеры: `0`, `42`, `1000`.
2. **Строковые литералы (`string`) (зарезервировано/не реализовано в текущей грамматике):** Последовательность символов в двойных кавычках `"`. Поддерживаются экранированные символы: `\n` (перенос строки), `\t` (табуляция), `\"` (кавычка), `\\` (обратный слэш).
    - Примеры: `"bor-forward"`, `"Error\n"`, `"\"quoted\""`, `"C:\\bin"`, `""`.
3. **Логические литералы (`bool`) (зарезервировано/не реализовано в текущей грамматике):** Ключевые слова `true` и `false`.

### Операторы и разделители

| Категория | Символы | Описание |
| :--- | :--- | :--- |
| Арифметические | `+`, `-`, `*`, `/` | Сложение, вычитание, умножение, целочисленное деление |
| Сравнения (зарезервировано) | `==`, `!=`, `<`, `>`, `<=`, `>=` | Лексически распознаются; в текущей грамматике не реализованы |
| Логические (зарезервировано) | `&&`, `\|\|`, `!` | Лексически распознаются; в текущей грамматике не реализованы |
| Присваивание (зарезервировано) | `=` | Лексически распознаётся; в текущей грамматике не реализовано |
| Разделители | `{`, `}`, `(`, `)`, `;`, `,` | Блоки кода, группы выражений, конец инструкции, разделитель параметров |

### Комментарии
Однострочные комментарии начинаются с `//` и продолжаются до конца строки. Многострочные комментарии не поддерживаются. Комментарии полностью игнорируются лексическим анализатором и не попадают в поток токенов.

## Синтаксис

Синтаксис описан в нотации ISO EBNF. Допускаются только программы, сводимые к нетерминалу `program`.

```ebnf
(* Программа: единственная функция main без параметров *)
program = "func", "main", "(", ")", block, end_of_file ;

(* Блок: последовательность инструкций в фигурных скобках *)
block = "{", { statement }, "}" ;

(* Инструкция: вывод значения либо вычисление выражения *)
statement = "print", expression, ";" | expression, ";" ;

(* Выражение: верхний уровень — сложение и вычитание *)
expression = additive_expression ;

(* Сложение и вычитание: левая ассоциативность *)
additive_expression = multiplicative_expression, { ( "+" | "-" ), multiplicative_expression } ;

(* Умножение и деление: левая ассоциативность *)
multiplicative_expression = unary_expression, { ( "*" | "/" ), unary_expression } ;

(* Унарный минус: правая ассоциативность *)
unary_expression = ( "-", unary_expression ) | primary_expression ;

(* Первичное выражение: литерал, ввод, вызов функции или скобки *)
primary_expression = integer_literal
                    | "readInt", "(", ")"
                    | identifier, "(", [ argument_list ], ")"
                    | "(", expression, ")" ;

(* Аргументы: одно или несколько выражений через запятую *)
argument_list = expression, { ",", expression } ;

(* Терминалы определены в разделе «Лексика» *)
identifier = ? определён в разделе «Лексика» ? ;
integer_literal = ? определён в разделе «Лексика» ? ;
end_of_file = ? признак конца исходного файла ? ;
```

## Приоритет и ассоциативность операторов

| Приоритет | Операторы | Ассоциативность |
| :--- | :--- | :--- |
| 1 (высший) | `-` (унарный) | Правая |
| 2 | `*`, `/` | Левая |
| 3 (низший) | `+`, `-` (бинарные) | Левая |

Вызов функции и группировка скобками выполняются раньше любых операторов.

## Семантика вычислений

### Тип данных
Единственный тип — `int`: 64-битное знаковое целое (диапазон от −2⁶³ до 2⁶³ − 1). Положительный литерал не должен превышать 2⁶³ − 1.

### Вычисление выражений
- Операнды и аргументы вычисляются слева направо.
- Операции `+`, `-`, `*`, `/` и унарный `-` выполняются с проверкой переполнения.
- Деление `/` — целочисленное, округление к нулю. Деление на ноль — ошибка.
- Инструкция-выражение вычисляется ради побочных эффектов.

### Встроенные функции

| Функция | Сигнатура | Результат |
| :--- | :--- | :--- |
| `abs` | `abs(int): int` | Модуль числа |
| `sqr` | `sqr(int): int` | Квадрат числа |
| `min` | `min(int, int): int` | Минимум из двух чисел |
| `max` | `max(int, int): int` | Максимум из двух чисел |

Имя функции и число аргументов проверяются при разборе.

### Ввод и вывод
- `print` выводит десятичное значение выражения с переводом строки.
- `readInt()` считывает целое число из стандартного ввода.

### Завершение программы
Инструкции `main` выполняются последовательно. Любая ошибка разбора или времени выполнения останавливает интерпретатор: сообщение печатается в `stderr`, код возврата ненулевой.
