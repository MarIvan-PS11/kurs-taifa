# Спецификация языка MiniSharp

## Введение

MiniSharp — императивный, строго типизированный язык программирования, предназначенный для обучения основам трансляции. Синтаксис языка вдохновлён C# и Pascal, что обеспечивает привычную структуру и высокую читаемость кода.

### Ключевые особенности
- **Строгая типизация:** Поддержка трёх базовых типов: `int` (целые числа), `string` (строки), `bool` (логические значения). Неявные приведения типов запрещены.
- **Императивная парадигма:** Программа представляет собой последовательность инструкций, изменяющих состояние через явно объявленные переменные.
- **Структурное программирование:** Поддержка блоков кода, условных операторов (`if-else`) и циклов (`while`).
- **Процедурный стиль:** Поддержка функций с параметрами и возвращаемым значением. Точка входа — функция `main`.
- **Минимализм:** Отсутствие сложных конструкций (классов, исключений, многопоточности) для обеспечения достижимости реализации в рамках семестра.

### Связь с другими языками
MiniSharp заимствует систему типов и синтаксис объявлений из C#, структуру блоков и точку входа из Pascal/C++, а также строгость типизации из обоих языков. Это делает его удобным промежуточным звеном для изучения принципов работы компиляторов и интерпретаторов.

## Лексика

Лексический анализатор разбивает исходный код на поток токенов. Пробельные символы (пробелы, табуляции, переносы строк) игнорируются, кроме случаев разделения идентификаторов и ключевых слов.

### Алфавит
- **Буквы:** Латинские буквы верхнего и нижнего регистра (`a-z`, `A-Z`).
- **Цифры:** Арабские цифры (`0-9`).
- **Специальные символы:** `_` (подчёркивание).
- **Разделители и операторы:** `{ } ( ) [ ] ; , . + - * / = < > ! & | "`.

### Ключевые слова
Зарезервированные идентификаторы, которые не могут использоваться как имена переменных или функций:

| Ключевое слово | Назначение |
| :--- | :--- |
| `let` | Объявление переменной |
| `if` | Условный оператор |
| `else` | Альтернативная ветвь условия |
| `while` | Цикл с предусловием |
| `func` | Объявление функции |
| `return` | Возврат значения из функции |
| `print` | Вывод значения в стандартный поток вывода |
| `read` | Чтение значения из стандартного потока ввода |
| `true` | Логическая истина |
| `false` | Логическая ложь |
| `main` | Точка входа в программу |

### Идентификаторы
Имена переменных, функций и параметров должны начинаться с буквы или символа `_`, за которыми могут следовать буквы, цифры или `_`.
- **Корректно:** `counter`, `_tempValue`, `user1`, `MAX_SIZE`.
- **Некорректно:** `1var`, `my-var`, `class`.

### Литералы
1. **Целочисленные литералы (`int`):** Последовательность цифр, опционально начинающаяся со знака `-`.
    - Примеры: `0`, `42`, `-15`, `1000`.
1. **Строковые литералы (`string`):** Последовательность символов в двойных кавычках `"`. Поддерживаются экранированные символы: `\n` (перенос строки), `\t` (табуляция), `\"` (кавычка), `\\` (обратный слэш).
    - Примеры: `"Hello"`, "Error\n", "\"quoted\""`.
1. **Логические литералы (`bool`):** Ключевые слова `true` и `false`.

### Операторы и разделители

| Категория | Символы | Описание |
| :--- | :--- | :--- |
| Арифметические | `+`, `-`, `*`, `/` | Сложение, вычитание, умножение, целочисленное деление |
| Сравнения | `==`, `!=`, `<`, `>`, `<=`, `>=` | Равенство, неравенство, меньше, больше, меньше/равно, больше/равно |
| Логические | `&&`, `\|\|`, `!` | Конъюнкция, дизъюнкция, отрицание |
| Присваивание | `=` | Присвоение значения переменной |
| Разделители | `{`, `}`, `(`, `)`, `[`, `]`, `;`, `,` | Блоки, группы, массивы, конец инструкции, разделитель параметров |

### Комментарии
Однострочные комментарии начинаются с `//` и продолжаются до конца строки. Многострочные комментарии не поддерживаются. Комментарии полностью игнорируются лексическим анализатором и не попадают в поток токенов.
